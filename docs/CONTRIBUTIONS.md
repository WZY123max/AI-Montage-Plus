> 基于 `ai-montage-agent` 开源版的二次开发记录。

> 范围：字幕引擎、转场引擎、渲染管线、WebUI、测试、仓库工程化

## 一句话概括

在开源版的基础上，我修掉了「字幕尾部丢失」「转场永远只有一种快闪」两条影响成片质量的核心缺陷，把转场从写死改成**可配置的节拍驱动系统**并接进 WebUI，重做了整站科技风前端；同时定位并修复了 4 个渲染管线的深层时序 bug，补齐 7 个自动化测试，最终用纪录片混剪与宣传片两条真实成片验证链路可用。

## 一、修掉的缺陷（现象 → 根因 → 方案）

### 1. 视频后半段字幕整段消失

- **现象**：成片最后 10~20 秒无人声区间完全没有字幕，观众听到旁白却看不到字。
- **根因**：歌词/字幕识别对齐（LRC + Whisper）在收尾处漏识别最后一句，该句被判为「未演唱」直接**丢弃**，时间轴上留下空档。
- **方案**：改为按**人声能量跨度**补回漏识别行，末句延到片尾并做渐弱；对齐报告新增 `vocal_end` 与 `notes` 字段，方便定位。
- **验证**：新增 `tests/test_lyrics_tail.py`，用真实漏识别样本回归。

### 2. 转场只有「快闪」一种风格

- **现象**：高级设置里明明有 11 种转场模板，成片里几乎全是同一种白闪，节奏单调。
- **根因**：三处叠加
  1. `plan_dynamic()` 收了 `transition_pattern` 参数但**从未真正使用**，永远走默认；
  2. `MAX_BEAT_XFADE = 0.18` 把单个转场时长压到 6 帧以内，视觉上就是一闪；
  3. 转场效果池误用了窗口池的变量名，池内容被覆盖。
- **方案**：
  - 打通模板透传链路，`auto` 模板改为**智能混搭**：10 种 xfade 按强弱拍轮换、相邻两刀不重复、约 60% 转场 + 40% 硬切保节奏、白闪占比降到 6%；
  - 转场时长改为 `d = min(trans_len, 0.45×镜头时长, 0.9×拍间隔)`，上限提到 0.40s；
  - 修复变量覆盖 bug，补 21 个 ffmpeg 7.x 新旧效果名映射。
- **验证**：新增 `tests/test_transition_mix.py` 6 个用例；27 个新效果名在 ffmpeg 7.1.1 全部可用；连续三段 0.40s 转场冒烟测试 6.000s 无黑场、无定格。

### 3. 转场「叠化时画面定格」

- **根因**：转场只对镜头最后一帧做插值，源镜头提前停住。
- **方案**：渲染器改为从源镜头**多取真实画面**参与叠化，转场期间画面持续运动。

## 二、新增的功能

### 1. 转场参数化（WebUI 高级设置）

新增三项可调参数，端到端打通前端 → API → 规划器：

| 参数 | 选项 | 默认 |
|---|---|---|
| 转场时长 | 0.25 / 0.40 / 0.55 / 0.70s | 0.40s |
| 转场密度 | 25% → 100%（每切必转） | 60% |
| 白闪强度 | 关闭 / 少量 / 较多 | 自动 |

改动文件：`packages/montage/creative.py`、`packages/montage/sync.py`、`packages/montage_engine/src/transition_patterns.py`、`packages/webui/src/app.py`（3 个 Form 参数 + 区间校验 + payload 透传）。

### 2. WebUI 整站科技风重设计

- 651 行漫画风 CSS **整段重写**为科技控制台风格：深色玻璃拟态面板、青紫霓虹描边、网格 + 扫描线背景、顶部状态栏与实时时钟。
- 支持一键切换浅色科技主题，偏好写入 `localStorage`。
- **约束**：所有 `id` / `onclick` / 表单字段名保持不变，纯样式层替换 → 功能零回归。

### 3. 字幕排版与可读性

- ASS 字幕支持**智能断行**（按语义与字宽切句，不出现单字尾行）。
- 亮背景下的字幕加**底部羽化渐变遮罩**，解决浅色画面里字幕发灰看不清的问题。
- 新增 `--burn-only` 参数：只重烧字幕、不重渲画面，改字幕从 20 分钟压到 2 分钟。

## 三、渲染管线稳定性（4 个深层 bug）

| 问题 | 根因 | 修复 |
|---|---|---|
| 成片掉帧、音画不同步 | xfade 输入端加了任何预处理滤镜就会丢掉帧率元数据 | 转场输入改为**裸输入**，预处理前置到单独渲染 stage |
| 输出少 1581 帧 | `-r 30` 对 variable-fps 素材做重采样 | 改 `-fps_mode passthrough` |
| 长链转场后时间轴回绕 | 13 级 xfade 串联导致 PTS 溢出 | 改为**逐级两输入**渲染 14 次再统一烧字幕混音 |
| 32.77s 之后画面冻结 | 短素材（3.5s/3.9s/5.6s）剪不满 6.5s 镜头时长 | `setpts` 慢放 + `tpad` 补足，重出片段 |

另修：AAC 编码后真峰值过冲 1~2dB → 母带峰值压到 −2dBFS + `loudnorm TP=-2`，抖音/YouTube 上传不再削波。

## 四、端到端验证（两条真实成片）

### 1. 纪录片混剪《归位》（客户真实素材，9 视频 + 5 图，无对标无文案）

- 原创钢琴 + 弦乐配乐（numpy/scipy 程序化合成，86.7s），TTS 低沉男声旁白，华文楷体字幕。
- Ken Burns 推轨 + 慢镜、逐级 xfade 渲染、底部渐变遮罩。
- **成片**：1080×1920 / 86.700s / 2601 帧 / 77.1MB / 平均 −15.8dB / 峰值 −0.7dB；配套文案与分镜表。
- 意义：验证了「无参考素材、无文案」场景下全链路可用。

### 2. 项目宣传片（30s + 60s 竖屏，9:16）

- 60s 版：1080×1920 / 1800 帧 / 68.8MB / H.264+AAC 48k / **I = −14.6 LUFS、真峰值 −0.8 dBFS**。
- 程序化原创配乐（128 BPM，十段结构与分镜严格对齐），所有切点落在拍点、段落边界等于小节线。
- UI 截图用 Playwright **元素级**抓取真实界面（整页截图会有坐标错位）。
- 逐帧 PIL+numpy 渲染 → rawvideo 管道 → H.264，不依赖剪辑软件。
- 交付物含发布文案、分镜表、封面建议。

### 3. 回归结果

- 零参数默认链路回归 **56 项通过**（唯一失败为环境未安装 pytest，非代码问题）。
- Python 编译 / JS 语法 / CSS 括号配对 / DOM id 引用 / 参数透传链路 全部静态检查通过。
